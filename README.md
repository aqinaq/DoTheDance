# Do the Dance

Қазақша би үйрену MVP. Қолданушы өз видеосын жүктеп, 60 секундқа дейінгі үзіндіні таңдайды. MediaPipe Pose Landmarker үлгі видеодан және камерадан дене нүктелерін табады. Топтық видеодан бір бишіні таңдауға болады. Қол, дене, аяқ бұрыштары мен дене өлшеміне келтірілген нүктелер тек сол бишімен салыстырылады; сенімсіз кадрлар есепке кірмейді.

## Іске қосу

```sh
npm install
npm run dev
```

`http://localhost:5173` бетін ашыңыз. Камераға рұқсат керек. Жарияланған нұсқа HTTPS арқылы жұмыс істейді. Модель мен WASM бірінші қолданғанда Google/JSDelivr көздерінен жүктеледі; видеолар мен камера кадрлары браузерден шығарылмайды.

## Тексеру

```sh
npm test
npm run build
```

## Шектеулер

- Үлгі видеодан 6 адамға дейін ізделеді. Әр адам міндетті түрде анықталады деген кепілдік жоқ; камера алдында бір қолданушы болуы керек.
- Талдаудан кейін анық кадрдағы нөмірленген жақтаудан бір бишіні таңдаңыз. Бақылау жолағындағы сұр кадрды басып, сол бишіні қайта белгілеуге болады. Басқа бишіге ауысу үшін алдымен таңдауды тазалаңыз.
- MediaPipe Full моделі толық кадрды және екі үлкейтілген бөлікті талдайды. Қайталанған анықтаулар біріктіріледі. Уақыт бойынша сәйкестендіру дене орталығының қозғалысын, өлшемін және киімнің кеуде тұсындағы түс үлгісін пайдаланады. Бет тану қолданылмайды.
- Жоғалған немесе екіұшты сәйкестіктен кейін автоматты қайта тану тоқтайды; қолмен жаңа белгі қажет. Бірдей киім, жабылу, күрделі айқасу және камера ауысуы әлі қате сәйкестік тудыруы мүмкін. Бақылауды визуалды тексеріңіз.
- Жарамды кадр пайызы таңдалған адам бақыланған және негізгі буындары сенімді көрінген үлесті көрсетеді. Жарамсыз аралықты көрші кадрмен алмастырып бағалау жасалмайды.
- Уақыт сәйкестігі 0,75 секундтық терезеден ең ұқсас қалыпты іздейді. Бұл толық музыкалық ырғақ талдауы немесе DTW емес; қолмен ығыстыру бар.
- Үлгі видео секундына 8 кадрмен алдын ала талданады. Үш көріністі толық модельмен өңдеу видеодан ұзақ уақыт алуы мүмкін. Камерадағы Lite моделі 8 кадр/секундқа дейін жұмыс істейді. Есептеу негізгі ағында, кадрлар арасында интерфейске кезек беріледі; әлсіз құрылғыларда кідіріс болуы мүмкін.
- Нәтиже кәсіби би бағасы немесе медициналық кеңес емес. Тарихқа тек есеп көрсеткіштері жергілікті сақталады.

## Топтық бейнемен тексеру

ILLIT видеосының 90–96 секунд аралығында бірнеше бишіні таңдау, таңдалған қаңқаны көрсету, жоғалған аралықты бағаламау және қолмен қайта белгілеу тексерілді. Екі қолмен белгіленген кадрмен 41% кадр бағалауға жарады; бұл тану дәлдігі емес, қамтылған кадр үлесі. Бұл сынақ толық 3:18 видео бойынша немесе барлық бишілер үшін дәлдік кепілдігін бермейді. Сынақ медиафайлы жарияланатын жинаққа кірмейді.

Модельдер: https://developers.google.com/edge/mediapipe/solutions/vision/pose_landmarker

### Бөлек айна баптаулары
Камера әдепкіде айнаша, видео бастапқы күйінде көрсетіледі. Екеуінің ауыстырғыштары бөлек. Қаңқа мен бишіні таңдау жақтаулары тиісті бейнемен бірге айналады. Салыстыру экрандағы қалыпты сәйкестендіреді: айна баптаулары әртүрлі болса, үлгінің координаттары мен сол/оң буындары есептеуде алмастырылады. Кеңестер мен белгіленген буын камерадағы адамның жағына сәйкес беріледі. Айна баптауын ауыстырғанда видео қайта талданбайды, камера сөнбейді. Төрт айна комбинациясы асимметриялық қалыппен автоматты тексеріледі.

### Тік студия интерфейсі
Үлгі және камера панельдері 9:16 форматында. Ноутбукта қатар, телефонда бірінің астына бірі көрсетіледі. Үлгі видео қиылмайды (көлденең видеода бос жолақтар сақталады). Камера ортасынан 9:16 қиылады: модельге дәл сол қиылған 360×640 кадр беріледі, қаңқа мен бағалау сол координаттарда есептеледі. Камерадан толық дене көрінуі үшін алыстау қажет болуы мүмкін. Айна басқаруы әр бейненің астында; баптау мен жаттығу бөлек қойындыларда.

### Камерадағы екі қаңқа
Жасыл тұтас қаңқа камерадан анықталған қимылды, күлгін үзік қаңқа үлгінің ағымдағы уақыттағы (қолмен ығыстыруды ескерген) қалпын көрсетеді. Үлгі жамбас ортасы мен иық-жамбас ұзындығы бойынша қолданушыға бейімделеді; бейне пропорциясы мен екі айна баптауы ескеріледі. Үлгі сенімсіз не жоғалған болса, немесе камерадағы толық дене анықталмаса, мақсат қаңқасы салынбайды. Бұл 2D бағыттаушы: жеке аяқ-қол ұзындығын немесе тереңдікті дәл қайта құрастырмайды.

### Жергілікті видео кітапханасы
IndexedDB видео Blob-тарын, талданған кадрларды, биші белгілерін және үзінді/жылдамдық/айна/уақыт ығысуы баптауларын сақтайды. Соңғы видео бетті жаңартқанда автоматты ашылады, таңдалған биші сақталған кадрлардан қайта бақыланады, модельді қайта жүктеп талдау қажет емес. Жазу транзакциясы аяқталған соң ғана «сақталды» көрсетіледі; сақтау қатесі мен орын жетіспеуі бөлек хабарланады. Кітапханадан видео ашу және растаумен өшіру бар. Камера видеосы жазылмайды, файл серверге жіберілмейді. Деректер тек осы origin/браузер/профильде: браузер дерегін тазалау не браузердің сақтау орнын босатуы оларды өшіруі мүмкін.

Тексеру: жергілікті Chrome-да арнайы жасанды WebM және 11 жасанды қимыл кадры/белгісі сақталды. Қолданба ашылып, айна баптауы өзгертіліп, бет қайта жүктелгенде видео Blob, 0.5× жылдамдық, үзінді, 11 белгі және жаңа айна баптауы қалпына келді. Тест жазбасы тексеруден соң өшірілді. Нақты quota exhaustion тексерілмеді.
