# Do the Dance

Қазақша би үйрену MVP. Қолданушы өз видеосын жүктеп, 60 секундқа дейінгі үзіндіні таңдайды. MediaPipe Pose Landmarker үлгі видеодан және камерадан дене нүктелерін табады. Қол, дене, аяқ бұрыштары мен дене өлшеміне келтірілген нүктелер салыстырылады; сенімсіз кадрлар есепке кірмейді.

## Іске қосу

```sh
npm install
npm run dev
```

`http://localhost:5173` бетін ашыңыз. Камераға рұқсат керек. Жарияланған нұсқа HTTPS арқылы жұмыс істейді. Модель мен WASM бірінші қолданғанда Google/JSDelivr көздерінен жүктеледі; видеолар мен камера кадрлары браузерден шығарылмайды.

## Тексеру

```sh
npm test
npm run build
```

## Шектеулер

- Бір адам, толық дене, камераға қараған қысқа үзінділер үшін жасалған. Айналу, жабылып қалған аяқ-қол және нашар жарық сенімділікті азайтады.
- Уақыт сәйкестігі 0,75 секундтық терезеден ең ұқсас қалыпты іздейді. Бұл толық музыкалық ырғақ талдауы немесе DTW емес; қолмен ығыстыру бар.
- Модель негізгі ағында 8 кадр/секунд шамасындағы жиілікпен орындалады. Әлсіз құрылғыларда кідіріс болуы мүмкін.
- Нәтиже кәсіби би бағасы немесе медициналық кеңес емес. Тарихқа тек есеп көрсеткіштері жергілікті сақталады.
